# **App Name**: BizSearch Platform

## Core Features:

- User Authentication: Secure sign-up and login functionality with business name and plan selection.
- Catalog Upload: Upload product catalogs in CSV/JSON formats with progress tracking and validation messages.
- Search Query Testing: Test search queries against the uploaded catalog and display results in real-time.
- API Credentials Display: Display Client ID, Access Key, and Base API URL with copy to clipboard and regenerate key functionality.
- API Integration Snippets: Display API request examples in cURL, JavaScript, and Python, auto-filled with user-specific keys. Reasoning tool selects correct snippet based on available details.
- Usage Metrics Dashboard: Display daily API request limits, usage, and graphs of historical usage with warning banners.
- Plan Management: View current plan details, upgrade/downgrade options, and billing history UI.

## Style Guidelines:

- Primary color: Deep blue (#293B5F) to evoke trust and professionalism.
- Background color: Light gray (#F0F4F8), nearly white, to provide a clean and spacious feel.
- Accent color: Teal (#3D948F), a muted but attention-grabbing color used to highlight important actions like button presses and value changes. (#3D948F)
- Body and headline font: 'Inter', a grotesque-style sans-serif known for its modern and neutral aesthetic.
- Use a set of consistent, minimalist icons to represent different functions and data points.
- Responsive layout that adapts to desktop and mobile devices, ensuring a consistent experience.
- Subtle transitions and animations to improve user experience and provide feedback.
